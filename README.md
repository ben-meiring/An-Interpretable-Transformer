# An Interpretable Transformer

This project studies a small autoregressive transformer trained on a controlled sequence-prediction task, with the goal of understanding its learned parameters in physically interpretable terms.

I trained a simple transformer to predict Markov chains on the surface of a 3D sphere. Because the underlying data-generating process is known, this provides a toy setting where we can ask whether the transformer’s learned weights and embeddings can be understood analytically.

## Motivation

Transformers are difficult to interpret because their learned representations are high-dimensional and highly redundant. My goal was to build a small transformer in a setting where the underlying dynamics were simple enough to understand, then analyze whether the model’s parameters could be interpreted geometrically or dynamically.

This is relevant to AI interpretability because safety-relevant understanding may require finding abstractions that make learned systems easier to describe, predict, and control.

## Basic setup

The model is trained on sequences generated by a Markov process on the surface of a 3D sphere. Each token corresponds to a position on the sphere, and the model learns to predict the next token from previous context.

I then modified the data-generating process to include more complicated sequence behavior, including memory effects and preferred tokens.

## Main result

After training, the model’s embedding space approximately reconstructs the geometry of the original sphere.

In appropriate coordinates, parts of the learned weight matrices can be interpreted as force-like and rotation-like terms governing transitions through embedding space. This suggests a dynamical-systems interpretation of the transformer:

* autoregressive generation defines trajectories through embedding space;
* learned weights shape these trajectories;
* positional encoding plays the role of time;
* token embeddings play the role of space.

In this small model, I was able to identify directions associated with longer context memory, attracting surfaces, limit-cycle-like behavior, and an approximate equation of motion for the most probable trajectory.

## Current status

This project is still in progress. The current code and visualizations demonstrate the basic phenomenon, but several parts of the analysis remain unfinished.

Open questions include:

* deriving a more complete analytic equation of motion for the expected position in embedding space;
* identifying which features are specific to this toy model;
* testing whether similar geometric or dynamical interpretations apply to larger transformer models.

## Why this matters

This toy model is not intended to be a realistic language model. Instead, it is a controlled system for studying how transformer parameters can implement sequence dynamics.

The broader aim is to understand whether some transformer behavior can be compressed into a smaller set of physically meaningful variables, such as trajectories, attractors, rotations, and memory directions. If this generalizes, it may provide a useful perspective for mechanistic interpretability.
